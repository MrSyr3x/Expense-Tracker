# 💰 Expense Tracker — Catppuccin Edition 🐱☕️

A beautiful and functional Expense Tracker designed with the soft, dreamy **Catppuccin color palette**.  
Track your spending, visualize income vs. expenses, and stay financially zen 🌸💸

---

## 💡 Highlights
- 🪙 **Add & Manage Transactions** — easily track income and expenses  
- 🧾 **Categorization** — tag transactions (Food, Bills, Travel, etc.)  
- 📈 **Dynamic Balance Updates** — auto-calculates total income, expenses & remaining balance  
- 🎨 **Catppuccin Theme** — pastel hues for a calm, aesthetic interface  
- 💾 **Local Storage Support** — data persists even after refresh  

---

## 🧠 Tech Stack
- HTML — Layout and structure  
- CSS — Catppuccin-styled design with soft gradients  
- JavaScript — Logic, validation, and local storage  

---

## 🚀 How to Use
1. Add your income and expense details  
2. Choose a category and click **Add**  
3. Watch your totals update instantly
